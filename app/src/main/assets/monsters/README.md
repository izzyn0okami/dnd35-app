# Imagens dos monstros

Envie as imagens das criaturas nesta pasta.

## Convenção de nomes

- Use preferencialmente o nome da criatura em letras minúsculas, sem acentos e com palavras separadas por hífen.
- Formatos recomendados: `.webp` (preferencial), `.png` ou `.jpg`.
- Exemplo: `dragao-vermelho.webp`.
- Não substitua nem renomeie imagens já enviadas sem necessidade; criaturas com nomes iguais ou variantes devem ser conferidas antes da associação.

Após o envio, as imagens serão conferidas e vinculadas aos identificadores corretos do catálogo de monstros. Imagens sem correspondência clara serão separadas para revisão, sem associação automática incorreta.
