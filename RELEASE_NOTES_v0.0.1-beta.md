# Ficha D&D 3.5 para Android — Beta v0.0.1

## Sobre esta versão

Primeira versão beta planejada para distribuição pública do companion Android de fichas de D&D 3.5. O aplicativo foi pensado para apoiar a mesa presencial, mantendo os dados locais no dispositivo.

## Funcionalidades em destaque

- Criação e edição de fichas de personagens.
- Cálculo e consulta de estatísticas derivadas.
- Apoio a classes, perícias, talentos e magias do D&D 3.5.
- Cálculo automático de espaços de magia e magias conhecidas para as classes conjuradoras implementadas.
- Inventário com itens personalizados, fotos, carga e controle de munição.
- Consulta de estatísticas para combate.
- Exportação da ficha em PDF.
- Persistência local, sem dependência de serviço em nuvem para as funções atuais.

## Limitações importantes

- Esta beta ainda não inclui multiplayer local entre dispositivos.
- QR Code para sessões, modo Mestre, sincronização de pontos de vida/iniciativa, aprovação de ações, mensagens privadas, comércio entre jogadores e baú compartilhado são funcionalidades planejadas para uma etapa futura.
- O app auxilia o grupo, mas não substitui a interpretação das regras pelo Mestre.
- A compilação assinada requer a keystore de publicação do responsável pelo projeto; ela não é distribuída no repositório.

## Antes de publicar

- [ ] APK instalado e testado em um dispositivo Android real.
